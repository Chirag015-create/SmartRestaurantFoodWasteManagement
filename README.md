# Smart Restaurant Food Waste Management

## 📌 About the Project

**Smart Restaurant Food Waste Management** is a **demo web project** created for academic/learning purposes.

The main idea of this project is to demonstrate how a restaurant can record food preparation, track food waste, manage surplus food, and view basic reports from one system.

> **Note:** This is a demo project. Some features are only designed or simulated for demonstration and are not a complete production-ready system.

---

## 🎯 Main Features

* Staff Dashboard
* Food Preparation Records
* Food Waste Records
* Waste History
* Basic Food Demand Prediction
* Ingredient Stock Management
* Surplus Food Management
* Food Donation Records
* Donation Pickup
* Waste Reports
* Notifications
* Admin Dashboard
* User Management
* Food Item Management
* Dish Management
* Basic System Reports

---

## 👥 User Roles

### Staff / User

Staff can demonstrate:

* Adding prepared food records
* Recording food waste
* Checking waste history
* Viewing food demand prediction
* Checking ingredient stock
* Adding surplus food
* Managing donation information
* Viewing basic reports

### Admin

Admin can demonstrate:

* Managing users
* Managing food items
* Managing dishes
* Viewing system information
* Viewing reports
* Checking basic system activities

---

## 🤖 AI Prediction

The project contains a **demo AI Prediction feature**.

It is used to show how previous food/sales information could be used to estimate the required food preparation quantity.

This is a **basic demonstration**, not a complete machine-learning system.
